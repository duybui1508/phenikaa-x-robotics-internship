# Media naming guide

Add only self-recorded and publication-safe media.

Recommended filenames:

- `ros1_amr_model.png`
- `slam_map_preview.png`
- `astar_vs_dijkstra.png`
- `ros1_navigation_demo.mp4`
- `yolo_ok_ng_inference.png`
- `vision_pick_place_demo.mp4`
- `bldc_velocity_response.png`
- `tim320_safety_fields.png`
- `plc_hmi_warehouse_demo.mp4`

For GitHub performance, compress videos and keep each clip short. When a file is too large, upload it as a GitHub Release asset or use an unlisted video link with a thumbnail in the module README.
